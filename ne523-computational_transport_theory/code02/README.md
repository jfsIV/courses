# Compile
- run `make` to compile
- run `make clean && make` to recompile

# Execution
- run `./sn_2d <input_file>` to execute `test` & `ddsolve`

If you do not enter any command line arguments, `test.in` will be used as the input.

# Input Format
The input file is formatted as such:
`<psi_x_in> <psi_y_in>`
`<mu> <eta>`
`<dx> <dy>`
`<source>`
`<sigma_t>`
